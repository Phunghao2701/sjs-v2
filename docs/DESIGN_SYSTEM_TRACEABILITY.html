How to read the outlier flags

Mixed primitives

A page directly imports both react-bootstrap and shared/ui. This is a concrete migration boundary: same screen may combine Bootstrap components and Tailwind-based primitives.

Separate analytics namespace

Page is under src/trendingApp. Its wrapper loads trendingApp/shared/styles/tokens.css; aliases map old orange token names to shared blue, but chart series retain their own semantic colors.

Page CSS

Page module imports local CSS or CSS modules. Review selector scope, duplicated spacing/typography, and token usage against the shared foundation.

Evidence boundary

?Shared-first? means the direct page imports and shell are aligned by source evidence; it is not a pixel-level visual pass. Child components may still introduce legacy CSS or Bootstrap.

System entry points

App-wide cascade

src/main.jsx imports bootstrap-isolated.css, index.css, then shared/ui/ui.css. UI imports Tailwind and theme.css.

Dashboard shell

DashboardShell supplies researcher navigation; uses shared Button, Framer Motion, and app utility styles. Public catalog pages generally inherit it.

Admin shell

AdminLayout uses separate admin sidebar/header/footer and features/admin/admin.css; admin child pages still have notable React-Bootstrap imports.

Analytics shell

TrendingAnalyticsLayout wraps analytics routes, loads a dedicated token file and shared page layout/button. Analytics screen modules also import feature CSS/CSS modules.
